
# SOWISO

All the mathematical material and exercises for this course will be
done in an online environment called SOWISO, which you may or may not already
be familiar with. In SOWISO you can read theory pages describing the concepts
and can get automated feedback and hints for each exercise.

[You can join the SOWISO course using this link.](https://uva.sowiso.nl/saml/surf/ZW5yb2xsL0dpb0xIeU1XYm1CUDRYckM:)

**Note:** Make sure to set your language in SOWISO to English, as some of the
modules will not be available in Dutch.

## Mathematical foundations

During the first half of the course, each module will link to one or more
chapters in SOWISO for you to complete that week. These chapters will usually
be listed at the end of a module, as they'll contain material needed for the
theory of the algorithm for next week. 

Since all the exercises have automated feedback, your answers in the SOWISO
will not be graded. If you're already familiar with the topics in a chapter,
you may skip these exercises, but please check to make sure you can do all
of the exercises before starting the theory of the next module.
