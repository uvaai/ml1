
## Content of this module

This week will be a bit of an intermezzo, as we won't cover any new theory or machine learning algorithms. Instead focus on how to effectively use two very important libraries in machine learning, namely *Numpy* and *Pandas*. We've already seen some Numpy in the previous module, and how we can use matrix multiplication to speed up making predictions. As the models get larger and more complex, use *Numpy* will become essential, and it will also feature heavily in the algorithm for the last module. *Pandas* is data processing library built on top of *Numpy*, and it is extremely useful when reading in and cleaning up data from all sorts of sources, which is something we'll do a lot in *Introduction to Machine Learning 2*.
