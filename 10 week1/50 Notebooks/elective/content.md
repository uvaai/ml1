
# Installation instructions

Create an account on the main minAI page [here](https://minai.proglab.nl/syllabus) and join the "Elective Spring" schedule, if you haven't already. Follow the installation instructions for either Windows or Mac in the sidebar of the page to install the required tools for the course.

*Note:* We strongly recommend you use the provided Conda environment instead of using your own Python installation, as this environment comes with all of the required packages and tools already included. If you do choose to still run your own installation, then you must make sure that all modules included in each assignment are imported correctly, and the notebook can be run top to bottom without errors.
